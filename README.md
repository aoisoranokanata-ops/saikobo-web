# 彩工房 Web

iPad で使える画像編集アプリ。Windows 用の画像編集ソフト「彩工房」のモバイル版で、作品は `.sko` ファイルで Windows 版と行き来できます。
ブラウザ（Safari）で開いてホーム画面に追加すると、アプリのように全画面で使え、オフラインでも起動します。

公開ページ: https://aoisoranokanata-ops.github.io/saikobo-web/

## はじめに（iPad）
1. Safari で公開ページを開く → 共有ボタン →「ホーム画面に追加」
2. ホーム画面の「彩工房」から起動 →「＋ 新規」「写真から」「ファイルを開く」のどれかで始める
3. 作品は自動で保存されます（この iPad のブラウザの中）。大事な作品は `.sko` か PNG で書き出しておくと安心です

## 指と Apple Pencil の操作
| 操作 | 内容 |
|---|---|
| Apple Pencil | 描く。筆圧で太さ（ペンの種類によっては濃さ）が変わる |
| 2本指でつまむ・動かす | 拡大縮小・画面の移動 |
| 2本指タップ／3本指タップ | 取り消し／やり直し |
| 指1本 | Pencil を一度使うと「画面の移動」に切り替わる（表示メニューで変更） |
| 指を置いたまま止める | スポイト（その場所の色を描画色に。輪の色で確認） |
| 画面の左端のスライダー | ブラシの太さ・濃さ（表示メニューで隠せる） |
| レイヤーの ≡ をドラッグ | 重ね順の並べ替え（開いたグループの見出しの下側に落とすとグループの中へ） |
| レイヤーを長押し | レイヤーのメニュー |
| マスクの小窓をタップ | マスクに描く（黒で隠す・白で見せる）。絵の方をタップすると戻る |

キーボードを付けた iPad や PC では、Photoshop と同じショートカット（⌘Z・⌘T・B・E・V など）も使えます。

## できること
- **描く**: ペン 8 種類（標準ペン・Gペン・丸ペン・鉛筆・チョーク・マーカー・エアブラシ・水彩）、消しゴム、塗りつぶし、グラデーション、スポイト、文字
- **選ぶ**: 長方形・楕円・なげなわ・自動選択（新規・追加・削除・共通）、反転・ぼかし・拡張・縮小
- **整える**: 移動、自由変形（拡大・回転・反転・遠近）、切り抜き、画像の回転・反転・サイズ変更・カンバスサイズ
- **色**: 色調補正 16 種（レベル補正・トーンカーブ・色相・彩度・カラーバランス・色温度 など）、フィルター 15 種（ぼかし・シャープ・ノイズ・モザイク・周辺光量 など）
- **あとから直せる編集**: レイヤーマスク、テキストレイヤー、調整レイヤー、レイヤースタイル（影・光彩・境界線・カラーオーバーレイ・内側の影）、
  クリッピングマスク、グループ（通過モード・不透明度・マスク）
- **保存と書き出し**: 自動保存、`.sko`（Windows 版と同じ形式）、PNG・JPEG（共有シートから写真やファイルへ）

## Windows 版とのやり取り
- iPad → Windows: ファイル ＞「彩工房ファイル（.sko）で書き出し」→ 共有シートの「ファイルに保存」で iCloud Drive などへ → Windows 版で開く
- Windows → iPad: Windows 版で保存した `.sko` を iCloud Drive などに置き、作品一覧の「ファイルを開く」で開く
- レイヤー・マスク・テキスト・調整レイヤー・スタイル・グループもそのまま行き来でき、合成した絵は両方でほぼ同じになります（差は平均 1 段階未満）
- フォントは端末ごとに違うので、文字を直したときはその端末にあるフォントで描き直されます（直すまでは元の見た目のまま）

## Windows 版との違い
- Windows 版だけ: Claude Code 連携、ComfyUI での生成、被写体の選択、PSD の読み書き、ノイズを軽減
- Web 版だけ: 色調補正の「色温度・色かぶり」（調整レイヤーには使えません）
- 描画モードのうち一部（ディザ合成・ビビッドライトなど、メニューで「≈」付き）は近い計算で表示します

## うまくいかないとき
- **上のバーに「● 未保存」が出る**: 端末への保存がうまくいっていません。自動でやり直します。押すと理由が出ます。続くときは書き出しておいてください
- **動きが重い・落ちる**: 大きな作品（長辺 4000px 前後）はメモリを多く使います。新規作成の画面に、その大きさで使えるレイヤー数の目安が出ます
- **作品が消えないようにしたい**: ホーム画面に追加して使うと、Safari に消されにくくなります。作品一覧の「⋯」→「保存領域を確保する」も試してください
