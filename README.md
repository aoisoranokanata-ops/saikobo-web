# 彩工房 Web

iPad で使える画像編集アプリ。Windows 用の画像編集ソフト「彩工房」のモバイル版です。
ブラウザ（Safari）で開き、ホーム画面に追加するとアプリのように使えます。作品はその端末のブラウザの中に保存されます。

## 使い方（iPad）
1. Safari で公開ページを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面の「彩工房」から起動 →「＋ 新規」または「写真から」

| 操作 | 内容 |
|---|---|
| 2本指でつまむ・動かす | 拡大縮小・画面の移動 |
| 2本指タップ | 取り消し |
| 3本指タップ | やり直し |
| Apple Pencil | 筆圧でブラシの太さ（設定で濃さも）が変わる |
| 指1本 | Pencil を使うと「画面の移動」に切り替わる（表示メニューで変更可） |
| レイヤーの ≡ をドラッグ | 重ね順の並べ替え |
| レイヤーを長押し | レイヤーのメニュー |

書き出し（ファイル ＞ PNG／JPEG で書き出し）は共有シートが開くので、「画像を保存」で写真に入ります。

## できること（フェーズ1）
- ブラシ・消しゴム（筆圧・硬さ・手ぶれ補正）、塗りつぶし、グラデーション、スポイト
- 選択: 長方形・楕円・なげなわ・自動選択（新規・追加・削除・共通）、反転・ぼかし・拡張・縮小
- レイヤー: 追加・複製・削除・並べ替え・不透明度・描画モード・透明部分のロック・結合
- 移動、切り取り・コピー・ペースト、画像の回転・反転・サイズ変更・カンバスサイズ・切り抜き
- 取り消し・やり直し（ヒストリーから任意の時点へ）、自動保存、オフラインで起動

## フェーズ2で増えたこと
- ペンの種類: 標準ペン・Gペン・丸ペン・鉛筆・チョーク・マーカー・エアブラシ・水彩（オプションバーの「ペン ▾」）
- 色調補正: 明るさ・コントラスト、レベル補正、トーンカーブ、露光量、自然な彩度、色相・彩度、カラーバランス、色温度、白黒、
  レンズフィルター、反転、ポスタリゼーション、2階調化、自動トーン など（絵を見ながら調整、選択範囲の中だけにもかけられる）
- フィルター: ぼかし（ガウス・ボックス・移動）、メディアン、ノイズ、シャープ、アンシャープマスク、ハイパス、モザイク、エンボス、
  輪郭検出、周辺光量、雲模様
- 自由変形（拡大・回転・反転・遠近）、切り抜きツール（比率を選べる）

## Windows 版との違い
Claude Code 連携・ComfyUI 連携・PSD は Windows 版だけの機能です。
描画モードのうち一部（ディザ合成・ビビッドライトなど、メニューで「≈」付き）は近い計算で表示します。
